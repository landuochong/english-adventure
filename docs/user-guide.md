# Campus Quest 使用说明

Campus Quest 面向青少年，用预设地图任务练习英语听力和口语。学生自己行动、提问和完成委托；Nova 负责陪伴、解释与建议。

当前为脚本原型，没有接通生成式 AI、真人教练联机、账号或发音评分。

## 本地启动

在项目目录运行：

```sh
npm start
# 打开 http://127.0.0.1:4173/
```

已有服务时直接打开该地址。修改代码后刷新页面即可，不需要部署。音色、语速和进度保存在当前浏览器，线上网址与本地网址不共享数据。

## 选择冒险

主页有 Pip 主线，以及六个独立的日常场景：课前借书、咖啡馆点餐、挑选帽子、去博物馆、周末公园计划、邀请新伙伴。可以直接玩任意场景，不需要先完成 Pip。

每个日常场景按照以下顺序进行：

1. 进入语言背包，听关键词和常用短语，选择音色与语速并试听。默认请求 Google US English、0.85×；浏览器未提供该音色时请手动选一个可用英语音色。也可以选择“暂用文字体验”。
2. 点击“准备好了，出发”。教练说明场景及第一步，地图解锁。
3. 用方向键、WASD 或点击地面移动。也可以点击远处人物，走到其身边；走近后会出现红色问号。
4. 点击任务发起人的问号，人物会主动讲述委托，不需要先问“任务是什么”。先听清需求，后面的人物不会替你决定答案。
5. 走近其他人物，点击问号或按 E，用英语提问或回应。正确表达当前所需的信息后，任务才推进。单独说关键词、随便打招呼、缺少关键要求，都不会直接过关。
6. 同一个人物还有待完成的回应时，头顶保留红色问号，点击人物或问号即可继续语音输入；录音中再次点击可结束。对话区的独立小喇叭随时用于重听。当前阶段全部完成才把头顶标记变成喇叭；后续任务需要再次回应这个人物时，会恢复问号。“开口交流”或 E 也可以再次提问。完成其他人物处的行动后，回到最初的同伴，自己说明结果。
7. 所有要求完成后，人物感谢你并出现庆祝效果。此时可进入冒险回顾、重玩本场景或选择其他场景。

左侧导航按进度解锁：地图需要主动开始，线索手记需要领取任务，冒险回顾需要完成委托。

## 听不清楚时

先使用“重听”或“慢速重听”。冒险中可在 Nova 面板调整语速，语言背包可更换音色，设置会记住。所选音色不可用时停止播放，不会悄悄换成 Albert。

英文和中文默认收起，确实需要时再展开“需要文字帮助”；文字体验模式会展开辅助内容。线索手记只记录你已经亲自获得的信息，不提前公开完整故事或未完成步骤的答案。

## 和教练讨论

新增场景的桌面版教练面板位于地图右侧，滚动时保持可见。窄屏点击右下角固定的“问教练”入口展开；可点击“收起”或按 Escape 返回地图。

Nova 默认跟随，也可以在“陪伴方式”切换为语音陪伴。教练只给建议，不替你借书、点餐、邀请、交付或完成任务。

- “听建议”：根据当前进度提醒下一步。
- “讨论刚才的信息”：拆开刚才听到的信息，帮助理解。
- 问“Could you say that again?”：重听正在讨论的信息。
- 问“What does borrow mean?”等：解释本场景已收录的关键词。
- 在线索手记中点“和教练讨论”：讨论指定的一条已获得信息。

教练和人物目前都使用有限脚本与规则，未覆盖的合理说法可能无法识别；可以换一种表达。这里不评估发音，也不会因为求助而扣分。

## 语音输入与文字替代

第一次使用麦克风时按提示开启。说话过程中持续显示识别内容，连续静音 2 秒后结束，也可以主动点“说完了”。尚未定稿的识别片段会请你确认，不会直接提交。取消不会触发人物回答。

语音活动检测使用本地 Silero VAD；转写依赖浏览器 SpeechRecognition，可能通过浏览器厂商远程服务进行。应用不保存录音。不支持语音识别、权限未开启或网络失败时，可展开“暂时无法开口？打字交流”，文字采用相同任务规则。

## Pip 主线

学习语言背包 → 在广场找 Mia 领取任务 → 向 Ben、Amy、Leo 提出与机器人相关的问题并获得三条线索 → 根据线索去温室附近探索 → 集齐线索并靠近才发现 Pip → 点击 Pip 或按 E 听它的感谢 → 完成庆祝与回顾。

## 保存、重玩与检查

点击“返回主页”或“场景列表”会结束并重置当前冒险，停止录音和播放；下次进入需重新准备语言、领取任务。音色、语速和其他场景的进度保留。场景内切换语言背包、地图、手记不清空进度；未主动退出时刷新页面仍能恢复。已完成场景也可以在回顾中选择“重玩本场景”。场景内的“重置进度”会确认后只重置本场景。

开发检查：

```sh
npm test
node build_standalone.js
```

`dist/standalone.html` 是同步生成的页面入口，修改模块后需重新生成。语音模型仍使用 `vendor/` 资源，建议通过本地 HTTP 服务访问。

本轮默认仅本地预览；明确要求发布后才上线。

## 分轮交流与纠错

六个日常场景的主要行动支持分几句话完成，人物只追问尚未说明或需要纠正的部分。例如点餐时先说食物，再回应是否加洋葱，最后说饮料；更正饮料时不必重复整个订单。

在借书或点餐的对应步骤，遇到 MacBook、without the audience 这类已知歧义，人物会先询问确认。可以回答 Yes / No，也可以直接重说正确内容；未确认不推进任务。此功能是场景规则，不会自动修复所有识别错误。需要时展开“查看本次原始输入”，检查实际收到的文字；原始输入不持久化保存。

问路场景中，如果向司机问去博物馆的公交时 bus 被识别成 boss，司机会先确认“Do you mean which bus goes to the museum?”。回答 Yes 或重说正确问题后才获得线索；No 会取消这项确认。

## 本机识别测试入口

使用 http://127.0.0.1:4174/ 测试本地 SenseVoice；服务未启动时在项目目录运行 `npm run start:local-asr`。这个入口说完后才显示转写，仍以连续静音 2 秒结束，也可点击“说完了”。识别失败可以重说或打字，不会改用云端识别。音频仅在本机内存处理。4173 仍为浏览器识别；新端口需重新选择音色和语速。识别有误时可查看原文、多轮纠错；当前效果还需真人录音验证。

### 原声重听与显式保存样本

本地 4174 识别完成后，“本次语音输入”内可点击“重听我的原声”。播放的是实际送入模型的 16 kHz PCM 录音（经过浏览器麦克风处理及采样转换），不是重新合成识别文字；下一次录音替换上一段，普通游戏录音不写盘。

专用测试页：http://127.0.0.1:4174/voice-lab.html 。用户点击开始、说话、停止，可先试听；点击“保存并识别”后，才将 WAV 保存到 `data/asr-samples/`，用于同一音频的模型对比。此目录在 Git 忽略列表中，不对静态网页开放。每段最长 30 秒；对照原句不作为识别提示发送。保存成功但识别失败仍保留文件。当前仅展示 SenseVoice 结果，尚未接入其他模型对比。

## 当前本地识别：Whisper small（2026-10-21）

本节覆盖此前 SenseVoice 接入说明。4174 已切换为本机 whisper.cpp 的 small 模型，固定英语；`npm run start:local-asr` 不再启动或依赖 voice-tools 的 8032 服务。默认读取本机 `~/whb/music/models/ggml-small.bin` 和 PATH 中的 `whisper-cli`，可用 `WHISPER_MODEL`、`WHISPER_CLI` 指定安装路径。当前 CPU 模式每次请求加载模型，本次真实接口两条短句分别耗时约 7.9 秒和 2.0 秒（不含录音和静音等待），未保证长录音延迟。

游戏按场景传标识，后端仅使用白名单场景词汇提示，不包含任务答案、路线数字或隐藏线索；无效场景标识使用无提示识别。对比页可选场景或无提示，对照原句不发给模型。原声重听和两秒静音结束保留。CLI 所需录音写入私有临时目录，在正常完成、异常或超时后删除；不是纯内存处理。只有用户显式保存的对比样本长期保留在 Git 忽略目录。

验证：83 项 JavaScript 测试和 3 项后端测试通过；真实 4174 HTTP 接口用用户前两段原声均返回 Please take bus 5.。这不代表任意录音都准确；此前七段对照测试仍有一段错误。仅本地更新，未发布、未提交。

## 添加课程素材（2026-10-22）

主页点击“用课程创建故事”，或打开 `/course-entry.html`。可粘贴课程文字、用 ⌘V / Ctrl+V 粘贴截图、选择或拖放 PNG/JPG/WebP 图片，支持预览与移除。可填写水平、补充表达/语法、希望练习的情境。最多 8 张图，每张 5 MB，总计 20 MB。

点击“保存草稿与修改”保存一份当前草稿到此网址的浏览器 IndexedDB，包含图片；刷新和返回主页后可继续编辑，后续保存覆盖上一版。草稿不上传、不进入项目 Git；清除浏览器数据会丢失。图片识字与重点提取已接入本地模型，使用方法见下节；故事生成尚未接入。

## 本地课程学习重点提取（2026-10-22）

课程素材页已接入本机 Ollama `qwen3.5:9b`。需先运行 Ollama（本机可用 `OLLAMA_HOST=127.0.0.1:11434 OLLAMA_NO_CLOUD=1 ollama serve`），再运行 `npm run start:local-asr`。不下载模型、不调用云服务；模型未启动/不可用时提示失败，原材料和上次结果保留。4173 静态预览不提供提取后端，请使用 4174。

贴入课文或图片后点击“提取本课学习重点”。图片送入模型前最长边缩至 1600px，原始图片仍保存在浏览器草稿。图片先识字，再根据识字原文提取，返回核心词汇、短语、句型与语法、中文含义、原文依据、来源标记及图片识字原文。可以修改、增删条目，核对模糊图片。无匹配依据、单词误列为短语等条目标为“待核对”，需处理后确认。语义质量仍需人工检查，不把模型输出当作标准答案。

点击“保存草稿与修改”或“确认学习重点并保存”，结果与素材一起保存到当前浏览器。材料或要求发生变化后原结果标记过期，需重新提取再确认。确认后仍不生成故事，故事生成功能尚未接入。模型输出格式异常、空结果或截断不会显示成功；繁忙时提示重试。

## 从课程重点生成互动故事（2026-10-22）

确认学习重点后，点击“生成互动故事”。本机 Qwen 编排 4～5 个情节（领取委托及 3～4 个互动步骤），使用现有地图；每份故事支持 2～3 个人物。单次最多 24 个学习重点，材料多时请拆课。模型调用约需数分钟，不保证每次生成都能通过检查。

作者可编辑背景、台词和教练建议，查看课程覆盖与补充表达。高级编辑可调整完整 JSON，包括人物、可接受表达、追问和条件；只接受固定数据结构，不执行生成代码。检查会核对 ID、有效地图、前置台词来源、至少一次变化、多轮信息收集和最后回访。检查不能判断剧情是否有趣、英语是否自然或语义是否完全正确，需要作者试玩核对。检查失败保留草稿，修改后再检查或重新生成，不进入学生列表。

点击“试玩当前故事”会先保存课程和故事草稿，再进入现有语言背包与地图。走近委托人点击问号先听任务；其他人物需学生开口，支持分轮、乱序补全和显式更正，例如 “No, I meant water”。不明确的更换会追问确认，冲突或未知否定表达不推进。人物和教练均为配置台词与有限表达规则，不是开放式 AI 对话。教练不授予任务进度；重听不推进，最后回到委托人汇报才完成。生成故事的 Whisper 识别当前使用无场景提示，尚未把生成词汇动态写入 ASR 上下文。

生成故事页面可“返回故事编辑”。作者核对并试玩后勾选确认，再保存到“我的故事列表”；主页可进入已保存故事。预览草稿不出现在公开场景列表。课程草稿保存在 `campus-course-drafts`，可玩故事单独保存在浏览器 IndexedDB `campus-generated-stories`，均不上传云端。清理浏览器数据会丢失；localhost 与 127.0.0.1 属于不同存储空间。保存故事会创建新版本，旧版本进度不套入新版本；返回主页重置当前任务，保留音色和语速。

### 学习重点卡片与试玩检查

来源字段不再显示；点击“查看原文依据”才展开出处。红色 × 位于每条右上角，用于删除该条。被模型标为待核对的条目，需要核对后勾选确认，或删除。

“开始试玩”在故事顶部，并随滚动保持可见。检查通过即可试玩，无需先勾选“已完成试玩”；后者仅用于保存到正式故事列表。生成后的错误会自动尝试修复一次，仍不通过时显示原因，并可点击“自动修复故事”。修复不会跳过检查，未成功的结果保持草稿。生成与修复完成后自动保存课程草稿，保存失败会显示提示。高级“恢复已有故事配置”可恢复持有的 JSON 草稿，恢复后仍需通过同样的检查才能试玩。

任务完成弹窗统一显示三颗星，作为完成奖励；交流次数、重听和纠错不会扣星，不代表发音或语言能力评分。
