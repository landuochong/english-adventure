# Campus Quest — 英语同行冒险

版本：0.2 · 2026-10-17 · 状态：样板关卡与交互原型

## 产品共识
面向青少年，以预设场景中的任务驱动英语听说。学生是行动主角，教练可以同行跟随、观察、交流、提供信息与语言帮助，不能代办任务。默认同行模式，可切换对讲机语音陪伴。真人和 AI 教练共享权限边界。

目标用户暂定 12–15 岁、A1–A2；这是一项产品假设，待用户测试验证。单局目标时长 15–20 分钟，不强制倒计时，不因求助扣分。

## 样板关卡：消失的科技节机器人
迎宾机器人 Pip 离开展台。学生作为志愿者，在教练 Nova 陪同下询问目击者、收集线索、找到 Pip 并带回广场。

地图：科技节广场、图书馆、美术教室、温室、体育馆。地点自由探索，任务状态不由位置或聊天模型随意决定。

|阶段|学生行动|信息与语言目标|完成条件|
|---|---|---|---|
|准备|学习六个词、三个短语；听辨位置|robot/library/greenhouse/behind/flashing/button|完成练习，或明确选择已掌握跳过|
|简报|在广场领取任务|白色机身、蓝色灯|学生主动领取|
|目击|在图书馆询问管理员|Have you seen a small robot?；去往美术教室|成功发起相关询问，获得目击线索|
|调查|在美术教室检查设备记录、询问成员|蓝灯闪烁；装饰物被搬到温室|学生主动收集两条信息|
|辨认|在温室比较两台机器人|结合颜色和灯光辨认目标|拥有三条线索并选择蓝灯 Pip|
|唤醒|询问操作、按绿色按钮、发出跟随指令|Press the green button；Follow me|学生按按钮并表达跟随意图|
|返回|带 Pip 回广场，主动交付|汇报发现|Pip 已跟随且学生提交任务|
|迁移|听新位置描述并选择；口头/文字回顾|behind the gym 等新组合|展示实际练习情况，不伪造语言评分|

## 教练与提示
教练自动跟随学生位置，语音模式隐藏地图上的教练。提供三级提示：回忆线索、指出信息、具体方向。不得自动触发领取、拾取、辨认、唤醒、跟随或完成。主动帮助不应频繁打断。

真人后续方案：独立教练身份、房间邀请、音频通话、独立角色移动/自动跟随、只读学生任务进度；服务器拒绝教练发出的任务变更命令。未成年人不提供陌生人公开匹配。

AI 后续方案：服务端语音与对话接口，模型只产生对话和提示建议。确定性任务引擎维护线索、物品和完成条件。向模型仅提供当前角色可知的信息。不得把客户端密钥嵌入网页。

## 原型实现范围
实现响应式网页、语言准备、可连续移动的二维校园地图、跟随角色、场景互动、脚本教练、三级提示、线索本、英语 TTS、浏览器语音识别（支持时）、文字替代、复盘、浏览器本地进度与重置。

原型不是生成式 AI 或真人联机产品。界面明确标注脚本教练。自由输入采用有限意图匹配，无法覆盖所有同义表达；不支持的输入提供重述建议，不扣分。语音识别是可编辑转写，不是发音评测。面对场景人物时，语音识别的最终结果自动提交、识别提问意图并播放回答；识别失败可重试或使用文字。

默认不自动播放声音；点击播放后调用系统英语语音。不支持语音时保留文字。开始识别前提示：浏览器可能把音频发送给其语音服务，不保存录音。无后台、无账号、无真实教师、无付费功能。

## 状态与持久化
状态包含 schemaVersion、准备状态、当前位置、任务阶段、已收集线索、是否唤醒/跟随/完成、练习次数、模式。使用版本化 localStorage；数据损坏回退初始状态，存储不可用时使用会话内存并提示。聊天、原始语音和个人身份不保存。

状态转换必须具备前置条件。重置需要确认。重新开始清除任务数据。任务进度与语言练习记录分开，不把提示次数、文本输入或游玩时长包装为口语能力评分。

## 交互与视觉
清新校园探险风格：暖白底、森林绿导航、淡绿地图、橘色任务点。桌面左侧导航、中间探索、右侧教练；移动端纵向布局。人物使用可聚焦按钮，支持方向键 / WASD 连续移动及鼠标 / 触屏点击行走，地图装饰不参与可访问名称。音频可重播/停止，字幕可切换，支持减少动画偏好。

## 验收
1. 可从词汇准备完整玩到带回机器人并进行变式练习。
2. 可自由探索，但不能跳过线索直接完成；教练提示不改变任务状态。
3. 同行/语音切换不丢进度，刷新恢复任务。
4. 错误机器人、按钮、询问和变式选择均可重试。
5. 无麦克风权限或语音 API 时，文字路径仍能完成任务。
6. 桌面与手机无关键操作遮挡，键盘可操作。

## 后续开发顺序
先验证此闭环；再接入生成式教练与流式语音；然后实现真人房间和权限；最后扩展关卡编辑器、跨设备学习记录与难度适配。正式上线前设计监护与数据保留机制，验证任务对听说迁移的实际效果。

## 试用观察
邀请 5–8 名目标学生，记录主动提问、独立决策、听后行动、提示依赖及变式理解。比较练习前后同难度新任务，不根据通关率单独判断学习有效性。


## 0.2 交互修订：场景中的移动与提问
此节替代 0.1 的“点击地点切换、在教练输入框收集线索”。

- 学生有连续位置，方向键 / WASD 移动，点击地面或人物后自动走到目标位置；移动需耗时，不能瞬移。此样板地图为开放地面，建筑作为背景标识，暂不模拟室内与障碍碰撞。
- Nova 独立位置跟随，语音陪伴模式隐藏角色；学生进入文字输入时暂停移动，失焦清空按键，防止角色自行滑动。
- 人物交谈半径 85 世界单位。靠近且该人物还有任务信息时，头顶出现红色问号；获取线索后消失。超出范围不能远程取得线索。
- Mia 是任务发布者；Ben 提供图书馆目击线索；Amy 提供装饰物去向；Leo 提供设备记录；Max 提供支线信息。
- 靠近后自动出现人物姓名、开口提问按钮、重听和文字替代；E 键开始语音提问。首次说明浏览器语音服务，用户开启后使用一次性录音。最终转写自动进行有限意图匹配，并播放该人物回答。
- 语音不启动后台持续监听；识别期间角色停止移动，回答时停止采集以避免回声识别。离开人物时停止其播放，清除当前对话；重复请求只能重播当前人物的回答。
- 仅任务引擎能授予线索。Nova 面板只处理求助，不再代理 NPC 发放线索。
- 新验证：移动边界、到达距离、线索标记状态、人物回答路由、未知提问、语音失败降级、远处不可提问、键盘不干扰输入、跟随和语音模式切换。

## 0.3 教练开场与低成本求助
- 每次进入先展示教练开场卡，说明场景、角色关系和根据已有进度计算的下一步。点击一次“听教练介绍，开始/继续冒险”播放英语介绍与中文字幕，避免依赖浏览器未授权的自动发声；不要求开启麦克风。
- 新用户先准备语言，再进入地图；完成准备时自动播报“先去 Mia 领取任务”。老用户继续现有进度，不重置关卡。
- 地图上方常驻“Nova · 下一步”，任务阶段变化时更新。标出目标只高亮人物，不自动走路、收集线索或完成任务。
- 教练主入口为“一键交谈”，说完自动回答；两个常用问题“下一步做什么？”和“这句话怎么说？”一键播报。文字求助折叠呈现，支持中文及英文的常见意图。语音识别目前仍为英语。
- 无语音识别、无权限或无声音时保留中文文字与快捷问题。场景人物的回答优先播放，不与教练叠音。教练基于有限意图和真实任务状态指导，不具备开放式生成对话能力。
