# 停下来的笔

外研社新版七年级上册英语 · Unit 1 *A new start* · 互动剧本设计稿

开学第一天，王涵在《论语》里夹下一张书签。第一节英语课上，他在黑板上看见了刚读过的那句话，笔却停在了署名处。旁边的小林已经把整句抄到了迎新展签上。

- [分场剧本](分场剧本.md)按演出顺序收录课前序幕、课堂主线、两条可选支线和课后扩展剧情。
- [角色卡与试演](角色卡与试演.md)供分角色排练和核对本课学习目标时使用。

**游戏内所有对话一律使用语音。** 角色的每句台词都要播音，玩家通过麦克风提问、回答或转述。字幕和释义按需展开。书页、黑板和展签供玩家阅读，夹书签、递书、改署名可以直接动手。[项目设计规则](../../design.md)

课堂里王涵发现署名问题、犹豫后举手的情节取自 *The first lesson*。蓝书签、借书、补笔记和迎新展签是原创扩写。英语对白为试演示例，具体词句和整单元覆盖程度待对照实际课本核定。[课文教学设计](https://zy.21cnjy.com/21130891)
