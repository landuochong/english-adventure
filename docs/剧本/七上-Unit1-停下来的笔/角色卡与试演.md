# 《停下来的笔》角色卡与试演

每位演员只读自己的角色卡。道具为两本相似的书、一张蓝书签、一块黑板和两张黄色展签。三至五人可按出场顺序兼角，主线加一条支线暂按 8–10 分钟设计，扩展约 5 分钟，实际时长待试演。

| 角色 | 你知道什么，想办成什么 |
|---|---|
| 王涵 | 早读时你帮梅夹了书签。你觉得老师写的名字眼熟又不对。想好先问谁，再用自己的话说明。 |
| 梅 | 夹蓝书签的书是你的。上课前你把它借给了本。有人来找书时，告诉他现在该去找谁。 |
| 本 | 梅的书在你这里。听清对方要借哪一本，再把书交给他。 |
| 陈老师 | 给学生留出开口的时间。听到哪里就问到哪里；有人说清署名和依据时，动手更正。 |
| 小林 | 你把黑板上的话抄好送去了迎新展。上课时留心同学说了什么，下课后你要去找那张卡。 |
| 迟到的同学 | 你只看见擦过的黑板。问清改动再补笔记。 |
| 布展同学 | 你拿到两张卡，没听过刚才的课。请来找你的人说清哪一张、哪一处要改。 |
| 参观的同学 | 你看见展签上有修改的痕迹。找布展的人问问是谁改的。 |

## 学习观察

- **单词**　王涵能否听懂追问，用 *sentence、name、mistake* 指出有问题的是署名？
- **短语**　换成小林的视角后，学生能否用 *put up his hand* 或 *point out the mistake* 转述自己先前做过的事？
- **语法**　听到 *mine、it、him* 后，学生能否找到借书人，用完把书还给书主？第二轮换一位同学借书，观察学生能否相应换用 *her* 或 *me*。
- **语音**　收起字幕，从梅第一次请人帮忙到展签更正，逐轮检查角色的台词是否能听到、学生能否口头接话。学生卡住时先提示关键词，再按需给半句示例。
