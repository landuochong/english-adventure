## 本地试玩

校园首页的「开学剧场」打开[独立剧场地图](../../dist/school-plays.html)。在报到处进入《入学仪式》，在早读教室进入《停下来的笔》，在教室门外进入《我的名字叫 Fine 吗？》。演出中可打开地图查看当前位置，按剧情走到另一处；两篇 Unit 1 使用教室与走廊的分场地图。各课单独保存进度，完成后可进入下一课、再演一次或回到地图。这是二维场景与口语回合组成的本地原型。对话接受预设意图和关键事实，尚需通过学生试演扩充能识别的表达。

4174 使用项目原有的本机 Whisper small 英语识别，4173 使用浏览器英语识别。角色默认沿用校园音色；浏览器缺少该音色时，可以手动选用随剧场附带的离线英语录音。录音由本地 Flite SLT 合成，动态昵称在这套录音中读作 “my friend”。字幕可按需展开。
