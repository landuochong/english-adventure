# 《我的名字叫 Fine 吗？》角色卡与试演

备两张空桌牌、一支笔和两张手绘小图。三人即可演主线。演支线时，潘老师的演员可以改演本；采访时再换成记者。分别发卡，示例对白留给带演者。

| 角色 | 你知道什么，想做什么 |
|---|---|
| 安 | 你画了猫。刚认识门口的同学，有点紧张，希望进班后别人能记住你的名字。听清问话再决定怎样回答，也可以请求重听。 |
| 梅 | 你画了月亮，想知道搭档叫什么。她卡住时可以小声解释老师问了什么，留给她自己开口的机会。 |
| 潘老师 | 你第一次见这两个孩子。听清名字再写桌牌，请她们各自介绍对方的画。孩子答岔了，给她再介绍一次的机会。 |
| 本 | 你来帮忙收拾桌子，没听到两人的介绍。先问画属于谁，再递给你听到的那个人。 |
| 小记者 | 你错过了课堂。分别听两个人怎么讲，从中选一件事播给全班，两位当事人都能来纠正你。 |

## 这次试演观察什么

| 语言目标 | 能从哪一个动作或回应看出来 |
|---|---|
| 情绪词 *nervous*，短语 *feel better* | 门外和介绍结束后，分别让安告诉搭档自己感觉如何，允许前后感受不同。 |
| *introduce* 和 *introduce yourself / your partner* | 听完要求，学生能否从介绍自己转为介绍身边的人，并让老师认出她的画？ |
| *I / me / my / mine*，*she / her / hers* | 本故意向安询问梅的画，看安能否说明画是谁的。换一轮交换画作，观察回答是否随之变化。 |
| 从第一人称转述为第三人称 | 记者只听采访，不看角色卡。记下听众能否说清是谁紧张、谁展示了谁的画。学生若选择直接引语，可换人追问 “What did she say?”。 |

演后各用一句话记录两件事：哪一句追问让搭档听明白了，哪一次带演者需要给词语提示。留作和《停下来的笔》及后续剧本一起回顾的材料。
