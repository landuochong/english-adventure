# 我的名字叫 Fine 吗？

外研社新版七年级上册英语 · Unit 1 *A new start* · 第二个剧本

选材接在《The first lesson》之后。第 19 页的代词练习是一篇日记：潘老师请新生介绍自己，学生一紧张答成了问候语，老师用一个关于名字的玩笑化解了尴尬。第 20 页请同伴谈谈第一节课。剧本把两项活动连起来。搭档梅、人物名安、桌牌和迎新采访是原创扩写。[教材第 19–20 页公开文本](https://www.yeyulingfeng.com/wendang/91248444.html)

- [分场剧本](分场剧本.md)从走廊排练演到两人互相介绍，可接桌牌支线与课后采访。
- [角色卡与试演](角色卡与试演.md)可单独发给演员，附本课的单词、短语和代词观察点。

**全程语音对话。** 所有角色台词均播音，玩家通过麦克风开口。桌牌和画作供观察，字幕按需展开。下文英语是示例，学生可按自己的意思组织语言。
