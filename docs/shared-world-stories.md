# 统一世界与多地图故事设计

2026-11-12，现行方向；本地实现继续位于 feature/future-campus-2026-11-12。

## 世界组织

校园是主地图，科学中心、庭院、咖啡馆、商店、图书馆等属于校园内的区域。人物有稳定身份和世界坐标，故事引用人物，不为每篇故事复制一个独立页面或重建人物系统。学生自由行走，AI/真人教练只陪伴、分析与提供建议，不执行学生的任务。

当教学情境不适合校园（如户外、森林探险），使用独立地图。不同地图共用人物交谈、语音输入、线索判断、背包、任务进度和完成反馈；每张地图单独定义边界、地形、碰撞、人物位置和出生点。不得把森林等未实现地图作为可玩入口。

## 故事接入约定

故事入口配置 world、region、giver、people、目标位置与交付位置、物品呈现类型、学习词汇、asrScene、完成对白。地图注册在 campus-world.js；故事注册和运行接口在 campus-missions.js。当前运行接口为 config、state、marker、hint、act；场景层只读取状态并提交学生动作。

- 每次只推进一个当前故事，人物每次处理一个当前任务。阶段完成后问号变为文本标记，下一次需要该人物时再变问号。
- 学生先听场景语言背包，再到人物身边领任务；点击发布者直接听委托，询问对象需要学生开口。
- 多轮对话可累积信息、允许不同顺序和纠错；教练、重听和装饰物不会授予任务进度。
- 目标物需满足线索条件并实际走近才发现，领取和交付为学生主动动作。
- 切换故事前结束录音和播报，不把上一故事的线索、携带物或对白用于下一故事。
- 新故事必须配置识别主题与核心词汇。识别提示不是答案硬替换；原始识别结果保留。
- 新地图实现自己的场景构建器并复用上述任务接口；未来跨地图切换要管理资源释放和出生位置，不能只更换地图名称。

## 验证

- 六个日常故事均有统一地图适配层完整任务测试：远程/隔墙不推进、教练不改状态、多轮交流、领取前不能跳至汇报、最后手动确认/交付。
- 使用浏览器实际生成的小地图碰撞矩形重建行走范围，检查 17 位人物和 5 个物品任务领取点从出生点均可到达附近。
- 浏览器通过文字辅助完整走通购物故事：问价、选帽、走近发现、领取、带回、汇报、交付、三星结果；完成后继续下一故事会更换语言背包与识别场景。实际走过庭院→商店→图书馆。浏览器无错误。
- 真人麦克风口音准确率尚未逐个故事复测；测试通过不代表所有口音都能识别正确。

## 当前边界

- 八个内置故事已接入同一校园。购物是游戏内预设情节，不接入支付；问路是获取出行信息，不模拟乘车或博物馆参观。天气任务是策划公园活动，不代表已制作独立森林地图。
- 森林/户外独立地图、跨地图资源切换仍待实现；不提供假入口。
- 课程自动生成故事仍用原试玩入口，尚未自动投放 3D 世界；后续需区域/人物绑定编辑与通路校验。
- 当前对话为规则和预设对白，非开放式 AI。真人教练联机尚未实现。
- 进行中的任务状态仍为当前会话状态，刷新或重新进入关卡会重新开始；完成记录保存在本机浏览器 localStorage，不跨设备同步。未发布。


## 关卡地图与完成反馈（2026-11-12）

主入口 index.html 改为校园关卡地图：八个地点标记对应八个真实关卡，点击显示简短事件引子、练习主题及预计时长，不展示解谜答案。所有关卡可选，不人为锁关。完成记录显示为勾选和总数；重玩不会重复累计。

选择关卡后直接进入对应区域的语言准备，完成准备再自主领取委托。首次选择音色语速，之后可展开调整。Jalor 从学生身边出发，不代做任务。自由探索入口允许学生在校园里走近发布者并点击选择其未完成委托；同一时间只进行一项。

午餐进阶关保留售罄转折，并新增独立的替代选项提问：学生得知鸡肉售罄后，必须主动问还有什么，再回去与 Lily 商量，最后分次补齐食物、配料和饮料。基础点餐故事不受该分支影响。判断仍是规则匹配，不是开放语义理解。

完成时默认三星，可回到校园看结果、进入下一未完成关或返回地图。午餐交付后餐桌出现三明治和饮水，代替只有弹窗的反馈；本机完成记录可用于后续探索中的陈设展示，但不替学生完成重玩任务。存储不可用时提示本次完成无法保存。

原课程与二维试玩保留在 practice.html；课程生成页的试玩链接指向该页，旧首页 ?play= 链接自动转入，避免丢失既有课程入口。自动生成故事仍未接入 3D 世界。

验收：122 项 JavaScript 测试及 17 项 Python 测试通过；浏览器使用文字辅助完整走通进阶午餐关，确认替代询问、分次点餐、发现领取、汇报交付、餐桌变化；回到地图并刷新仍显示 1/8。390px 宽度无横向溢出；原课程试玩入口可打开。未复测真人麦克风准确率，未修改识别服务。

### 借书交付提示修复（2026-11-12）
实际卡点为约定归还后尚未亲自领取，但 Lisa 的旧对白让人误以为书已在身上。3D 借书关现明确说明课本在 Lisa 身旁领取台；未领取时点击 Tom 或 Lisa，播放领取提醒，不重播原始委托。亲自领取后向 Tom 说 Here you are / Here you go / Here it is 也可进入手动交付；未拿书或否定持有不会跳关。浏览器通过文字辅助完整验证领取、Here you are、交给 Tom、三星完成；本轮未改语音识别。

### 任务人物持续交谈（2026-11-12）
当前故事相关人物即使没有待办问号，也可以点击身体或已有标记交谈。非待办阶段先说 Hello，保留“继续交流”录音入口，文字默认折叠；发布者首次仍主动发布委托。学生可打招呼、道谢、请求重复，或询问已获任务信息；非当前步骤的问题复述该人物已说的信息，不揭示未来线索，不推进任务。未领取、待交付阶段提供相应操作提醒。问号只表示当前待办，不再决定能否录音；教练权限和真实距离/视线检查不变。
当前为预设规则和上下文复述，不是任意问题的 AI 问答，也不逐句抽取回答。自由探索中的发布者仍负责选择故事；跨故事无关人物不新增开放对话。本轮浏览器确认 Tom 发布任务后能再次打招呼、启动录音，并用文字追问归还时间；未实测真人语音准确率。

### 切关跟随与移动速度（2026-11-12）
机器狗由直线寻路改为复用校园避障寻路，采用统一世界边界；暂停、语音输入或切关准备结束后清除过期路径并重新规划，不在每帧重置路线。保留原机器狗模型和协调步态，通过小时间步提高跟随节奏。玩家普通速度由 1.4 提至 2.1 m/s，Shift 由 2.8 提至 3.8 m/s；普通移动保持 Walking，快走使用 Running，动画仍按实际位移调速。浏览器完整完成借书关并点击下一关进入点餐准备，再移动、转向，机器狗继续跟随，无控制台错误；124 项现有回归测试通过。未改语音识别，未发布。

### 点餐自然表达修复（2026-11-12）
用户实际识别原句为 Hello, I prefer the chicken sandwiches without onions.，旧规则只识别单数 sandwich 且长句未接纳 prefer，导致持续追问食物。现支持 sandwiches 和 prefer，保留跨轮食物/配料/饮料累积；错误餐品和否定句不通过。浏览器用该原句确认只追问饮料，补 water 后亲自领取成功；126 项测试通过。识别服务未改动。

### 随身任务背包与语言学习册（2026-11-12）

八个关卡使用各自词汇短语；切关清除旧委托记录，打开背包读取新关卡内容。背包只是只读学习界面，打开时取消录音并暂停行走，关闭或 Esc 后恢复，不推进或重置任务。自由探索且无当前任务时显示未选任务，不展示上一关学习册。复用既有音色和语速设置，慢听为当前语速的 0.8 倍。

### 入学仪式（2026-11-12）
新增新生第一关 welcome，内置关卡总数为九；旧关卡 ID 及完成记录不变，显示序号后移。复用 Mia 作为迎新老师，Lisa / Kai / Sue 分别介绍图书馆、咖啡馆和运动区。老师先欢迎并介绍学校；学生分轮说称呼与爱好（允许昵称，不索取年龄、住址等），再任选至少两个地点亲自交流，顺序自由。此关打招呼是到场认识同伴的有效动作，但仅点击、重听或远程发言不记录参观。回到老师处分享实际参观过的地点，主动确认入学，三星祝贺后可继续探索。教练 Jalor 不代做。
