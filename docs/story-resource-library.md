# 故事场景与人物资源库

2026-11-12，本地第一版。

## 当前能力

课程创建页新增场景与人物选择。六个模板复用已有校园区域：图书馆（classroom）、咖啡馆（cafe）、商店（shop）、校车站（town）、草坪（park）、运动区（sports）。选择场景带出推荐人物和任务职责，作者可以替换。这里是故事创作模板，不是六张新建的独立 3D 地图。生成故事仍在二维试玩，自动投放 3D 地图尚未实现。

人物库从现有 17 位校园任务人物初始化。保存稳定 ID、姓名、固定身份、性格和说话特点；现有人物保留 worldCharacterId 关联。新增人物使用唯一 custom ID，仅在二维试玩使用通用形象，不自动创建 3D 模型。教练 Jalor 不参与任务人物选角。

## 数据与使用规则

- 一个故事选择 2～3 位不同人物，第一位为委托人 npc1；每个人在本故事有单独职责。固定身份与故事职责分开。
- 人物库保存在同浏览器同域 localStorage；可新增、编辑、停用、重新启用。停用人物不出现在新选角列表，旧故事不受影响。读取损坏或写入失败时明确提示，不覆盖坏数据或假装保存成功。
- 课程草稿保存场景和选角；人物档案独立保存，可以跨故事复用。修改选角会要求重新生成故事，不影响已确认课程学习重点。
- 生成请求携带 resources.scene 与 resources.cast，模型必须遵守场景主题、人物数量、姓名及 npc1 委托人约束；服务端和前端检查，不通过不保存为新故事。
- 生成后的故事保存 resources 快照；后续库内改名、停用不自动修改历史对白。已有未绑定资源的故事保持兼容，修复时保留旧人物。
- 快照包含世界区域和人物关联，为后续 3D 任务适配提供数据，但它本身不代表已完成 3D 位置、模型或交互投放。
