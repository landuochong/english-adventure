# Campus Quest · 英语同行冒险

先阅读 [设计文档](docs/design.md)。无构建依赖的网页原型，支持校园探索、脚本教练、语言准备、线索和复盘。

## 运行

```sh
npm start
# http://localhost:4173
npm test
```

静态文件在 `dist/`。通过 HTTP/HTTPS 打开，不直接使用 file://（ES modules 限制）。

## 试玩路径

完成准备 → 用 WASD / 方向键或点击地面走到 Mia 身边领取任务 → 走近 Ben、Amy、Leo，人物顶部红色问号提示未取得的线索 → 点击“开口提问”或 E 键，提出英语问题；最终转写自动处理并播放回答 → 走到 Pip 身边询问唤醒方式、按绿按钮、说 Follow me → 返回 Mia 身边交付。

文字替代：在人物对话区输入 `Have you seen Pip?` 并提问。Nova 面板只负责指导，不发放人物线索。

TTS 使用浏览器语音合成。语音输入依赖浏览器 SpeechRecognition 与麦克风权限，可能使用浏览器厂商的远程服务；不支持时可使用文字。语音最终转写自动处理；识别失败时可重试或用文字。进度仅在本浏览器保存，不保存聊天或录音。

本版是**脚本教练**，并非已经接通的生成式 AI。不含真人联机、账号、发音评分或云端学习记录。UI 不向学生展示虚假的语言成绩。
