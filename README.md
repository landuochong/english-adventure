# Campus Quest · 英语同行冒险

先阅读 [协作规则](AGENTS.md) 和 [长期记忆与成本复盘](docs/collaboration.md)，产品行为见 [设计文档](docs/design.md)。无构建依赖的网页原型，支持校园探索、脚本教练、语言准备、线索和复盘。面向最终用户的操作说明见 [使用文档](docs/user-guide.md)。

默认先讨论并汇总反馈，明确要求实施后统一修改；仅本地预览，明确要求发布后再上线。

## 运行

```sh
npm start
# http://localhost:4173
npm test
```

静态文件在 `dist/`。通过 HTTP/HTTPS 打开，不直接使用 file://（ES modules 限制）。

## 试玩路径

首次设置音色与语速 → 主页直接显示「日常英语小故事」场景选择（⭐ 主线冒险 + 6 个日常小故事）→ 点主线冒险卡片进入语言背包 → 点击“准备好了，出发”解锁地图等页面 → 用 WASD / 方向键或点击地面走近 Mia，点击问号听取并领取任务 → 走近 Ben、Amy、Leo，点击问号或按 E 提出任务相关的英语问题，识别后按规则回答 → 集齐三条线索后去温室走近隐藏的 Pip，点 Pip（或按 E）听它说感谢，随后弹出胜利庆祝。

六个日常场景：语言背包 → 主动开始 → 自己走近同伴听委托 → 向人物开口询问并行动 → 返回同伴汇报 → 庆祝与回顾。任务要求、距离和前置步骤均按规则校验；教练不代做。进度分别保存，不依赖主线进度。详见 [用户使用文档](docs/user-guide.md)。

文字替代：在人物对话区输入 `Have you seen Pip?` 并提问。Nova 面板只负责指导，不发放人物线索。

TTS 使用浏览器语音合成。语音输入依赖浏览器 SpeechRecognition 与麦克风权限，可能使用浏览器厂商的远程服务；不支持时可使用文字。语音最终转写自动处理；识别失败时可重试或用文字。进度与已获得的预设任务信息仅在本浏览器保存，不保存用户原始对话或录音。

本版是**脚本教练**，并非已经接通的生成式 AI。不含真人联机、账号、发音评分或云端学习记录。UI 不向学生展示虚假的语言成绩。


## 本地语音输入

语音活动由本地 Silero VAD 判断，确认说话后连续静音 2 秒才提交。中途停顿可以继续说，也可点“说完了”立即结束；界面显示累积转写，尚未定稿时需确认或重说。浏览器语音识别可能依赖其厂商服务；程序不能恢复识别服务没有返回的词。

模型与运行库在 `dist/vendor/vad/`，日常 `npm start` 不需要安装或构建。需要重新生成这些资源时：

```sh
npm ci
npm run vendor:vad
```

`npm test` 验证回合状态与转写处理。真实 VAD 的合成语音验收页面位于 `tests/browser/voice-qa.html`，从项目根目录启动 HTTP 服务后打开；它使用模拟 ASR，不会打开麦克风。真人语音识别准确率仍需在实际浏览器试说验收。

日常场景的任务数据、词汇和推进规则统一维护在 `dist/scene-engine.js`。改动后运行 `node build_standalone.js`，同步独立页面。
